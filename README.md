GI Oracle Profiler v1.4.0

E' un Tools per Oracle per catturare le query eseguite simile al profiler di Sql Server.
Strumento indispensabile per la manutenzione di applicazioni che usano tale Database server.

Include: Client SQL e JOB Manager.

(sia per Sistemi a 32 bit che per Sistemi a 64 bit):

oracleprofiler.zip 1395 KBytes (1.36 MB)

Requisiti di Sistema

Sistema Operativo richiesto: Windows XP Service Pack 3; Windows Vista Service Pack 1; Windows 7; Windows 8; Windows 10; Windows 11; Windows Server 2003 Service Pack 2; Windows Server 2008 e versioni successive.
 

Per poter funzionare richiede la presenza del .NET FrameWork v. 4.0 o versione successiva. Se sul S.O. non è presente il .NET FrameWork 4.0 è possibile installarlo scaricandolo dal sito Microsoft: dotNetFx40_Full_x86_x64.exe
 

Oracle Client versione 8.1.7 o successiva. Se sul S.O. non è presente è possibile installarlo scaricandolo dal sito Oracle: http://www.oracle.com




GI TextBrowser v1.0.1

E' un Browser Testuale che visualizza esclusivamente il testo delle pagine web ignorando immagini, colori, fogli di style e script.
Accetta argomenti sulla linea di comando in modo da poter essere eseguito come batch per esportare il contenuto delle pagine web.

(sia per Sistemi a 32 bit che per Sistemi a 64 bit):

gitextbrowser.zip 441 KBytes (0.43 MB)

Linea di Comando:

GITextBrowser.exe
url="http://www.iacosoft.com"
dest="c:\data\output.txt"
log="c:\data\output.log"

Altri parametri:
user= utente per l'autenticazione
password= password per l'autenticazione

Requisiti di Sistema

Sistema Operativo richiesto: Windows XP Service Pack 3; Windows Vista Service Pack 1; Windows 7; Windows 8; Windows 10; Windows 11; Windows Server 2003 Service Pack 2; Windows Server 2008 e versioni successive.
 

Per poter funzionare richiede la presenza del .NET FrameWork v. 4.0 o versione successiva. Se sul S.O. non è presente il .NET FrameWork 4.0 è possibile installarlo scaricandolo dal sito Microsoft: dotNetFx40_Full_x86_x64.exe
